# farsi-rtl-responses

Reply in Farsi (Persian) with RTL prose and strict LTR separation for shell, code, and paths. Use when the user writes in Farsi, asks for RTL answers, bilingual Farsi/English replies, or readable Persian formatting in Cursor.
