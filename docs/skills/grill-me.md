# grill-me

A relentless interview to sharpen a plan or design.

## Type

skill

## When to use

Invoke with `/grill-me`.

## Install

```bash
npx skills add mattpocock/skills -g -y -s grill-me -s grilling
```

## Usage samples

> /grill-me I want to add multi-tenant billing to this SaaS.


## Expected result

Relentless interview rounds that sharpen the plan. Writes no files.

## Separate CLI?

none

## Locations on this machine

`agents` → typically under `~/.agents/skills/grill-me` and/or `~/.cursor/skills/grill-me`.
