# grill-with-docs

A relentless interview to sharpen a plan or design, which also creates docs (ADR's and glossary) as we go.

## Type

skill

## When to use

Invoke with `/grill-with-docs`.

## Install

```bash
npx skills add mattpocock/skills -g -y -s grill-with-docs -s grilling -s domain-modeling
```

## Usage samples

> /grill-with-docs Align our order lifecycle language with the codebase and capture ADRs.


## Expected result

Interview + updates to `GLOSSARY.md` / ADRs as understanding sharpens.

## Separate CLI?

none

## Locations on this machine

`agents` → typically under `~/.agents/skills/grill-with-docs` and/or `~/.cursor/skills/grill-with-docs`.
