# domain-modeling

Build and sharpen a project's domain model. Use when discussing codebase terminology, writing or editing a GLOSSARY.md, or recording or editing an ADR.

## Type

skill

## When to use

Invoke with used by grill-with-docs / when editing glossary.

## Install

```bash
npx skills add mattpocock/skills -g -y -s domain-modeling
```

## Usage samples

> Sharpen terminology for Orders vs Shipments and update GLOSSARY.md.


## Expected result

Clearer domain language; glossary/ADR updates.

## Separate CLI?

none

## Locations on this machine

`agents` → typically under `~/.agents/skills/domain-modeling` and/or `~/.cursor/skills/domain-modeling`.
