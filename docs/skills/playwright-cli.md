# playwright-cli

Automate browser interactions, test web pages and work with Playwright tests.

## Type

skill + CLI

## When to use

Invoke with “Use `playwright-cli` to …”.

## Install

```bash
npm install -g @playwright/cli@latest
playwright-cli install --skills=agents --global
```

## Usage samples

> Use `playwright-cli` to test the login flow at `http://localhost:3000`. Capture console errors and a failure screenshot.


## Expected result

Browser automation evidence: snapshots, screenshots, console/network notes.

## Separate CLI?

`playwright-cli`

## Locations on this machine

`agents, cursor` → typically under `~/.agents/skills/playwright-cli` and/or `~/.cursor/skills/playwright-cli`.
