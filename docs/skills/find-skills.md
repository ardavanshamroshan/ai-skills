# `find-skills`

Helps users discover and install agent skills when they ask questions like "how do I do X", "find a skill for X", "is there a skill that can...", or express interest in extending capabilities. This skill should be used when the user is looking for functionality that might exist as an installable skill.

## Type

Agent skill (`SKILL.md`)

## Install

```bash
# If published on skills.sh / GitHub:
npx skills add <owner/repo> -g -y -s find-skills
```

Check [skills.sh](https://skills.sh/) or the skill’s upstream repo for the exact package.

## Usage

Ask the agent to use `find-skills` explicitly, or use the skill’s documented trigger / `$` / `/` command.
