# `caveman-stats`

Show real token usage and estimated savings for the current session. Reads directly from the Claude Code session log — no AI estimation. Triggers on /caveman-stats. Output is injected by the mode-tracker hook; the model itself does not compute the numbers.

## Type

Agent skill (`SKILL.md`)

## Install

```bash
# If published on skills.sh / GitHub:
npx skills add <owner/repo> -g -y -s caveman-stats
```

Check [skills.sh](https://skills.sh/) or the skill’s upstream repo for the exact package.

## Usage

Ask the agent to use `caveman-stats` explicitly, or use the skill’s documented trigger / `$` / `/` command.
