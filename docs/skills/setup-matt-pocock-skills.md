# setup-matt-pocock-skills

Configure this repo for the engineering skills: set up its issue tracker, triage label vocabulary, and domain doc layout. Run once before first use of the other engineering skills.

## Type

skill

## When to use

Invoke with `/setup-matt-pocock-skills`.

## Install

```bash
npx skills add mattpocock/skills -g -y -s setup-matt-pocock-skills
```

## Usage samples

> /setup-matt-pocock-skills


## Expected result

Repo configured for issue tracker, triage labels, domain doc layout.

## Separate CLI?

none

## Locations on this machine

`agents` → typically under `~/.agents/skills/setup-matt-pocock-skills` and/or `~/.cursor/skills/setup-matt-pocock-skills`.
