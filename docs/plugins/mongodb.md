# Plugin: MongoDB

Skills from the MongoDB Cursor plugin cover connection tuning, schema design, query optimization, Atlas Search / Vector Search, QE size estimation, natural-language querying, and MCP setup.

## When to open which

| Need | Skill direction |
| --- | --- |
| Indexes / slow queries | query optimizer |
| Data model | schema design |
| Search / vectors | search-and-ai |
| MCP wiring | mongodb-mcp-setup |
| Drivers / pools | mongodb-connection |

Use these when the MongoDB plugin is installed; otherwise prefer official MongoDB docs via [Context7](/rules/context7).
