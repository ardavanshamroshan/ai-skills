# Plugin: Postman

When doing non-trivial API work, the Postman plugin’s **`api-engineer`** skill is the default entry point and routes to specialized skills.

## Common skills

| Skill | Use |
| --- | --- |
| `api-engineer` | Orchestrator for design/implement/mock/test/monitor/docs |
| `bootstrap` | Link repo ↔ Postman workspace |
| `api-testing` / `api-mocking` / `api-monitoring` | Test, mock, monitor |
| `api-documentation` | Contract docs |
| `flows` | Postman Flows |
| `ci-integration` | CI gates |
| `variables` | Secret/value scoping |

## Result

Consistent API engineering workflow tied to Postman collections, environments, and monitors — not ad-hoc curl only.
